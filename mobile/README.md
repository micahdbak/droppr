# droppr mobile

The Expo (React Native) client for droppr.

## Get started

1. Install dependencies

   ```bash
   bun install
   ```

2. Start the app

   ```bash
   bun start
   ```

Screens and layout files live in `src/app` (file-based routing via [expo-router](https://docs.expo.dev/router/introduction)). All other application code lives elsewhere in `src`.

Read the versioned Expo docs at https://docs.expo.dev/versions/v57.0.0/ before writing new code.
